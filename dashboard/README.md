# AgentOps Dashboard

Vite + React + TypeScript dashboard for the AgentOps API (`../api`). See the root
[README.md](../README.md#dashboard-react--vite) for run instructions, environment
variables, and what each page does.

```bash
npm ci
cp .env.example .env.local   # then edit VITE_API_URL / VITE_API_KEY
npm run dev
npm run lint
npm run build
```
